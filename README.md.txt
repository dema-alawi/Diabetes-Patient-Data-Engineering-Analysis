# Diabetes Patient Data Engineering & Analysis

## Project Overview
This project focuses on cleaning, preprocessing, and analyzing a diabetes patient dataset using Python.

## Objectives
- Clean and preprocess the dataset.
- Handle missing values and convert data types.
- Transform categorical variables.
- Create new features using feature engineering.
- Prepare data for further analysis.
- Explore data patterns through visualizations.

## Data Engineering
The preprocessing steps included:
- Handling missing values.
- Converting data types.
- Creating features such as total visits and age midpoint.
- Creating patient risk-related indicators.
- Applying One-Hot Encoding and binary encoding.

## Exploratory Data Analysis
Visualizations include:
- Readmission distribution.
- Gender and readmission analysis.
- Number of medications and hospital stay analysis.
- Correlation heatmap.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Note
This project focuses on data engineering, preprocessing, and exploratory data analysis. It does not include training a machine learning prediction model.
